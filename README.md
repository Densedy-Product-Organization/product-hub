# Product Hub

Product Hub is a centralized product-information application for businesses whose product data is fragmented across spreadsheets, ERP systems, documents, websites, and internal tools.

## Status

Pre-development / Product Discovery

## Initial Goal

Provide a single source of truth for product records, taxonomy, attributes, variants, and supporting documents.

## Planned Editions

- Community
- Professional
- Enterprise

## Planned Channels

- Web Application
- REST API

## Planned Deployment

- SaaS
- Self-hosted
